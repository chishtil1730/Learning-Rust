# 🦀 Learning Rust: Project Git-Link

Welcome to my Rust learning journey! This repository tracks my progress as I transition from a complete beginner to building **Git-Link**, a custom CLI tool designed to bridge the gap between local development and remote repositories.

---



## 🛣️ Learning Roadmap

### Phase 1: The Fundamentals
* **Syntax & Basics:** variables, mutability, and primitive data types.
* **Control Flow:** Implementing logic with `match` statements, `if/let`, and loops.
* **Memory Management:** Understanding Rust: Ownership, Borrowing, and Lifetimes.

### Phase 2: Data & Logic
* **Strings & Casting:** Handling `String` vs `&str` and performing safe type conversions.
* **Data Structures:** Using Structs and Enums to model real-world data.
* **Collections:** Efficient data manipulation using Vectors and HashMaps.

### Phase 3: Connectivity (The Git-Link Core)
* **Custom APIs:** Building modular crates and internal APIs.
* **Networking:** Connecting local environments to remote servers.
* **External Integration:** * Fetching data via **REST APIs**.
    * Implementing complex queries using **GraphQL**.
